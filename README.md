- `thinKbox-2.3.0-linux-amd64.deb` — recommended Ubuntu/Debian/Linux Mint package
- `thinKbox-2.3.0-linux-amd64-portable.tar.gz` — portable build
- `thinKbox-2.3.0-LINUX-FINAL-BACKTEST.txt` — verification report
