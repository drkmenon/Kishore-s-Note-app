Install on Ubuntu / Debian / Mint

Download the .debSave Kishores-Notes-2.0.0-linux-amd64.deb to your Downloads folder.
Open Terminal in DownloadsThen install with apt:
sudo apt install ./Kishores-Notes-2.0.0-linux-amd64.deb
Launch Kishore's NotesOpen it from your Applications menu, or run:
kishores-notes

The Debian package declares libheif-examples, xdg-utils, and a supported browser engine as dependencies. Using apt is recommended rather than installing with dpkg alone.

Built-in verification

The packaged Linux release includes a self-test.

After installation, run:

kishores-notes --self-test

The expected result is:

SELF-TEST PASS: notes, JPG, real HEIC->JPEG, website export

Read the full Linux backtest report · SHA-256 checksums

Privacy & storage

Kishore's Notes is designed around local files. The application interface is served locally on your computer, binds only to 127.0.0.1, and uses a per-launch access token. Your notes remain on your machine unless you deliberately export or publish them.
