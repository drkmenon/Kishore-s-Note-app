KISHORE'S NOTES FOR LINUX — 2.1.0

Current final Linux release.

Features:
- Markdown
- [[Internal note links]] and backlinks
- Cloze
- Brain Map
- Search
- External web links
- JPG / PNG / WEBP / GIF images
- HEIC / HEIF -> JPEG conversion
- In-app image caption dialog
- Automatic Created and Modified dates

- Local notes in Documents/Kishore's Notes
