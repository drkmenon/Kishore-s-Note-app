KISHORE'S NOTES 2.1.0 — LINUX FINAL BACKTEST

GOAL
This Linux release was rebuilt to match the Mac 1.0.5 note feature set while
using a Linux-native local backend. It does not depend on Electron, Node.js,
Docker, or Python at runtime.

PLATFORM
- Linux amd64 / x86_64
- statically linked Go executable
- UI served locally at 127.0.0.1 and opened in the installed default browser
- notes stored in Documents/Kishore's Notes
- HEIC/HEIF conversion uses Linux heif-convert (libheif-examples)

MAC 1.0.5 FEATURE PARITY INCLUDED
- Andy-style linked-note pane layout
- last-five previous-note history / current note at right on large screens
- mobile top-down history layout
- accidental horizontal scrolling blocked
- New / Edit / Save
- automatic Created and Modified timestamps
- one-time timestamp migration for older notes
- Markdown headings
- bold / italic / bold-italic / strikethrough
- inline and fenced code
- bullet / numbered / task lists
- blockquotes / horizontal rules / tables
- [[internal note links]]
- automatic Backlinks
- cloze {{c1::answer}} and hints
- Markdown external links and bare web URLs
- JPG / PNG / WEBP / GIF
- HEIC / HEIF accepted and converted to JPEG
- in-app image caption dialog; no browser prompt()
- Search
- Brain Map
- Notes Folder
- Publish Website
- published website carries Markdown, images, links, backlinks and dates

RECOMMENDED PACKAGE
For Ubuntu / Debian / Linux Mint and related amd64 systems:
    Kishores-Notes-2.1.0-linux-amd64.deb

Install with:
    sudo apt install ./Kishores-Notes-2.1.0-linux-amd64.deb

Using apt is recommended because it installs the declared browser, xdg-utils,
and libheif-examples dependencies when needed.

PORTABLE PACKAGE
    Kishores-Notes-2.1.0-linux-amd64-portable.tar.gz

Extract and run:
    ./kishores-notes

Or install for the current user:
    ./INSTALL.sh

The portable version requires an installed graphical browser. HEIC/HEIF support
requires heif-convert; on Ubuntu/Debian install libheif-examples.
