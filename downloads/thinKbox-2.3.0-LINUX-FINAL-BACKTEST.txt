thinKbox 2.3.0 — LINUX FINAL BACKTEST

GOAL
Bring the Linux release to the thinKbox Mac 1.1.2 feature level without
breaking the existing local note store or previous Linux capabilities.

PLATFORM
- Linux amd64 / x86_64
- statically linked Go executable
- no Electron, Node.js, Python, or Docker required at runtime
- UI served only on 127.0.0.1 and opened in the default browser
- compatible data path: Documents/Kishore's Notes
- HEIC/HEIF conversion uses heif-convert from libheif-examples

Launch:
    thinkbox

    kishores-notes
